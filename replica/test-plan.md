# План тестирования CS2 CRAFT

Автотесты: `e2e/site.spec.ts` (Playwright, `npx playwright test`) на собранном сайте (`npm run build`, vite preview).
Каждый тест падает на ошибках в консоли, ответах 5xx и сломанных картинках самого сайта
(внешние картинки Steam / flagcdn не считаются — песочница их не видит).

Данные, которые собираются только в CI (страницы команд, логотипы, фото, профили), для локального прогона:

```bash
python3 tools/teams/build_teams.py --hist <matches-hist> --out public/data/teams
node scripts/fetch-logos.mjs --offline --store <копия logos-store> --hist <matches-hist> --out public/data
```
