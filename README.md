# RUSH B

Русскоязычный сайт обо всём в CS2 (раньше назывался CS2 CRAFT): каталог всех скинов с историей цен, калькулятор крафтов (оружие и ножи), стикер-крафты, паттерны, раскидки профи с 3D-повтором, коллауты, профили игроков и команд, расписание про-матчей с коэффициентами, статистика Steam, генератор прицела, утилиты и живой список серверов для дуэлей.

**Сайт:** https://vsemvamdam.github.io/rush-b/

## Что внутри

| Раздел | Что умеет |
|---|---|
| **Крафты** (`#/tradeup`) | Контракты 10 → 1 и 5 тайных → нож/перчатки. Шансы, флоат результата (нормированная формула), EV после комиссии Steam/Skinport, ROI, шанс профита, безубыточная цена входа, симуляция 1000 контрактов, пороги флоата для «Прямо с завода», ссылка на контракт. Учитывает правила на ноябрь 2026: StatTrak™, сувениры (с 21.05.2026), перчаточные кейсы, фазы Doppler. |
| **Скины** (`#/skins`, `#/skin/<id>`) | Все ~2000 скинов оружия, ножей и перчаток. Фильтры, сортировка по цене. Страница скина в стиле wiki.cs.money: износ со стрелками, ввод флоата и шкала FN–BS с диапазоном скина, паттерны, цены по износам (обычный/StatTrak™/сувенир), график цены за всю историю, «скрафтить этот скин». |
| **Стикер-крафт** (`#/craft`) | До 5 наклеек в любом месте, поворот, потёртость, брелок, стоимость сборки и оценка готового, «Осмотреть в CS2» (masked inspect link), `!gen`, PNG, ссылка, свои сохранённые крафты, случайный крафт. |
| **Паттерны** (`#/patterns`) | Fade %, фазы Doppler/Gamma Doppler, известные сиды Case Hardened и Marble Fade. |
| **Раскидки** (`#/nades`) | Все гранаты из про-демок, сгруппированные в раскидки: точки падения на радаре, позиции, откуда их кидают (пунктиром), фильтры по типу/стороне/игроку/турниру, «Мой набор». Окно раскидки — **3D-повтор прямо на сайте** по настоящей геометрии карты: «Видео» (бросок от первого лица → полёт за гранатой → результат), «Прицел» (Shift), «Позиция» (Ctrl), свободная камера, скачивание видео; клавиши броска (ЛКМ/ПКМ, прыжок, бег), `setpos`/`setang`, список профи — по клику повтор именно его броска из матча. |

| **Статистика** (`#/stats`, `#/stats/<steamid>`) | Любой профиль Steam по ссылке, SteamID или нику: уровень и XP (прогресс до следующего), игры и часы, топ игр, часы в CS2, пожизненная статистика CS2 (K/D, HS, точность, оружие, карты, последний матч), баны, друзья, инвентарь CS2 с оценкой по ценам сайта, история уровня/часов по дням и место в рейтинге. Рейтинг профилей (уровень, игры, часы, CS2, значки, возраст) с фильтром по стране; данные свежие при каждом открытии, рейтинг обновляется каждые 10 минут. |
| **Игроки** (`#/players`, `#/player/<steamid>`) | Профи из турнирных демок: K/D, ADR, HS, первые дуэли, AWP, урон гранатами, матчи, прицел из демки (с открытием в генераторе), раскидки игрока; вкладка «Команды». Страница команды (`#/team/<команда>`): состав, ближайший матч, все матчи с 2021 года, карты, титулы и колонка **«Новости»** — свежие заголовки о команде и её игроках из Cybersport.ru, Sports.ru, HLTV и Dust2.us. |
| **Матчи** (`#/esports`) | Турниры и матчи CS2: live, ближайшие матчи по дням (в местном времени), результаты, турниры (идут / скоро / завершены) с датами, призовым и местом. Фильтры по уровню (S/A/B/C), турниру и команде. Коэффициенты: лучший по источникам, оценка шанса без маржи, фаворит подсвечен. |
| **Дуэли** (`#/duels`) | Живой список всех CS2-серверов [Cybershoke](https://cybershoke.net/ru/cs2) — дуэли 1×1 и 2×2, арены, DM, ретейки, 5×5, сёрф, KZ, фан-режимы (~2400 серверов, обновление каждые 30 с). Фильтры по категории, стране и городу, карте, «Нас 2–5» (только серверы, где хватит мест на всю компанию), поиск по номеру/карте/IP. «Быстрое подключение» — самый живой сервер под фильтр со свободными местами. «Играть» запускает CS2 и сразу подключает (`steam://rungameid/730//+connect IP:порт`), 👥 копирует ссылку `#/duels?join=IP:порт` для друга, ⧉ — команду `connect` для консоли. |
| **Прицел** (`#/crosshair`) | Генератор прицела: коды нового формата `CS…`, попиксельный предпросмотр в выбранном разрешении (включая растянутое 4:3) на процедурных фонах или своём скриншоте, импорт старых кодов `CSGO-…` и команд консоли, экспорт в команды и `autoexec.cfg`, пресеты, проверенные прицелы профи, ссылка `#/crosshair?c=<код>`. |
| **Утилиты** (`#/tools`) | Перевод сенсы и eDPI, viewmodel, конфиг для тренировки, бинды, параметры запуска. |

## Как обновляются данные

Всё работает на GitHub Pages + GitHub Actions, сервер не нужен.

- **`.github/workflows/site.yml`** — каждые 6 часов и при каждом пуше:
  1. обновляет базу предметов из [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) (`scripts/build-db.mjs`);
  2. собирает текущие цены — Steam Market (минимальный лот и число лотов), Skinport (минимум, медианы 7/30 дней, фазы Doppler) и курс ЦБ РФ (`scripts/fetch-prices.mjs`);
  3. дописывает ежедневный снимок цены каждого варианта;
  4. собирает сайт и публикует его на Pages.
- **`.github/workflows/history.yml`** — полная история сделок Steam с первой продажи (`scripts/fetch-history.mjs`). Steam отдаёт её только авторизованному аккаунту, поэтому нужен секрет (см. ниже). Каждый запуск работает до 5 часов и продолжает с места остановки; первый полный проход по ~21 000 вариантов занимает 1–2 дня, дальше всё обновляется по кругу.
- Сами данные (цены, снимки, история) лежат не в git, а архивами в релизе **`data-store`** — история репозитория не раздувается.
- **`.github/workflows/news.yml`** — каждые 20 минут читает RSS-ленты Cybersport.ru, Sports.ru (раздел CS2), HLTV и Dust2.us (`scripts/fetch-news.mjs`) и раскладывает новости по командам для колонки «Новости» на странице команды. Новость попадает к команде, если в заголовке есть её название (как его пишет пресса: Spirit, NAVI, BETBOOM TEAM…), ник игрока или тренера из текущего состава; анонс новости может добавить команду, только если называет не больше трёх команд. Составы берутся с опубликованного сайта (`data/teams/info.json`, `data/rankings.json`). Публикуются только заголовки и ссылки — по файлу на команду в служебной ветке **`news-data`** (`t/<команда>.json`, force-push), новости хранятся 120 дней, на странице — до 60 за 90 дней.
- **`.github/workflows/esports.yml`** — каждые 20 минут собирает матчи и турниры (`scripts/fetch-esports.mjs`) и публикует один файл `esports.json` единственным коммитом служебной ветки **`esports-data`** (force-push — история не растёт). Страница `#/esports` читает его прямо из `raw.githubusercontent.com`, поэтому сайт для этого пересобирать не нужно.

### Матчи и коэффициенты

Источники: расписание, счёт и турниры — API Liquipedia (по правилам их API: свой User-Agent, gzip, не чаще 1 запроса в 2 с и 1 «parse» в 30 с — сборщик делает 1 такой запрос за запуск, остальное кеширует); цены на победу в матче — открытый API рынка предсказаний Polymarket (без ключа). Коэффициенты букмекеров — через [OddsPapi](https://oddspapi.io), для этого нужен бесплатный ключ. Без ключа страница работает: расписание, результаты и цены Polymarket видны, а вместо букмекеров стоит пометка «коэффициенты появятся после подключения ключа».

Как подключить ключ OddsPapi:

1. Зарегистрируйтесь на <https://oddspapi.io/en/sign-up> (почта и пароль, банковская карта не нужна). Бесплатный план — 250 запросов в месяц.
2. В личном кабинете скопируйте свой API key.
3. В репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret**. Name: `ODDS_API_KEY`, Secret: ваш ключ → **Add secret**. Больше нигде ключ не храните и никому не пересылайте.
4. **Actions → «Матчи и коэффициенты» → Run workflow**, поставьте галочку «Обновить коэффициенты OddsPapi прямо сейчас» → **Run workflow**. Через пару минут на странице появятся коэффициенты Pinnacle, 1xBet и Stake.

Одно обновление коэффициентов тратит 2 запроса; по умолчанию они обновляются раз в 7 часов (≈210 запросов в месяц, в лимит бесплатного плана). Расписание и цены Polymarket при этом обновляются каждые 20 минут. На платном плане можно чаще — в **Settings → Secrets and variables → Actions → Variables** задайте `ODDS_REFRESH_MIN` (интервал в минутах) и `ODDS_MONTHLY_LIMIT` (запросов в месяц); `ODDS_BOOKMAKERS` — до трёх букмекеров через запятую (по умолчанию `pinnacle,1xbet,stake`). Ключ передаётся только в запрос к API: в код, логи, ветку `esports-data` и на сайт он не попадает. Если ключ неверный, в логе будет «ключ не принят (401/403)», а на странице — пометка об этом.

Коэффициенты показываются справочно (18+), без ссылок на букмекеров — это не реклама и не рекомендация к ставкам.

### Полная история цен Steam

Steam отвечает «429 — слишком много запросов» на любой запрос истории цен с серверов GitHub (проверено: 0 предметов за 5 часов), поэтому историю собирают с обычного домашнего подключения. Вход в Steam не нужен — данные берутся со страниц предметов на торговой площадке.

1. На своём компьютере в PowerShell (нужен Node.js — `winget install OpenJS.NodeJS.LTS`):
   ```powershell
   mkdir $HOME\cs2-history -Force; cd $HOME\cs2-history
   curl.exe -L -o collect-history.mjs https://raw.githubusercontent.com/vsemvamdam/rush-b/main/scripts/collect-history.mjs
   node collect-history.mjs              # 600 самых продаваемых скинов, ~45 минут; --limit 1500 — больше
   ```
   Можно прервать (Ctrl+C) и запустить снова — продолжит с места остановки.
2. Получившийся `cs2-history.json.gz` прикрепить к релизу **data-store** (Releases → «Хранилище данных» → Edit → перетащить файл → Update release).
3. **Actions → «Импорт истории цен (с домашнего компьютера)» → Run workflow.** История попадёт на графики сайта и в астро-анализ рынка (`tools/astro/market_astro.py`).

> GitHub отключает расписания в репозиториях без активности 60 дней. Если цены перестали обновляться — зайдите в Actions и включите workflow обратно.

### Статистика Steam и CS2 (сервер профилей)

GitHub Pages не умеет делать запросы к Steam со своим ключом, поэтому для раздела «Статистика» есть маленький сервер на Cloudflare Workers (`worker/`, бесплатный тариф). Его разворачивает **`.github/workflows/worker.yml`**, адрес попадает в `public/data/api.json`.

1. **Ключ Steam Web API:** https://steamcommunity.com/dev/apikey (любой аккаунт, домен `vsemvamdam.github.io`) → секрет `STEAM_API_KEY`.
2. **Cloudflare:** зарегистрироваться на https://dash.cloudflare.com/sign-up, открыть **Workers & Pages** (при первом входе выбрать поддомен `*.workers.dev`), скопировать **Account ID** → секрет `CLOUDFLARE_ACCOUNT_ID`; My Profile → API Tokens → Create Token → шаблон **«Edit Cloudflare Workers»** + право `Account · D1 · Edit` → секрет `CLOUDFLARE_API_TOKEN`.
3. **Actions → «Сервер статистики (Cloudflare Worker)» → Run workflow** (или любой пуш в `worker/`).

Секреты — в Settings → Secrets and variables → Actions. Сервер хранит в базе D1 только публичные данные профилей, которые кто-то открыл на сайте (для рейтинга и графиков).

Тот же сервер отдаёт список для раздела **«Дуэли»**: `GET /api/servers` забирает публичный `https://cybershoke.net/api/api/v2/main/data` (его CORS пускает только сам cybershoke.net, поэтому напрямую из браузера нельзя), оставляет только CS2 и сжимает каждый сервер в короткую строку (~200 КБ вместо ~800 КБ). Ответ кэшируется на 20 секунд, а если Cybershoke недоступен — до часа отдаётся последний полученный список с пометкой `stale`. Ключи для этого не нужны. Код — `worker/src/servers.ts`, тесты — `tests/servers.test.mjs`.

**Ретранслятор (полный список).** Cybershoke выбирает, какие серверы показать, по стране запроса: Cloudflare получает только часть (нет Москвы, Казахстана, Ташкента…). Поэтому на отдельном VPS в Финляндии работает служба `cs2-relay` (`tools/cybershoke-relay/install.sh`): каждые 30 секунд она берёт полный список и отправляет его на `POST /api/servers/push`. Сервер сайта принимает его только с адресов из `RELAY_IPS` (`worker/wrangler.toml`), хранит в D1 (таблица `kv`) и отдаёт сайту, пока список свежее 2 минут; если ретранслятор молчит — берёт список сам (неполный, на сайте будет пометка). Установка на новый VPS — одна команда:

```bash
curl -fsSL https://raw.githubusercontent.com/vsemvamdam/rush-b/main/tools/cybershoke-relay/install.sh | sudo bash
```

Входящие порты не нужны; при смене IP сервера поправьте `RELAY_IPS`.

## Локальная разработка

```bash
npm install
npm run db            # скачать и собрать базу предметов в public/data
npm run dev           # http://localhost:5173/rush-b/
npm test              # проверка математики контрактов и inspect-ссылок
```

Без цен сайт тоже работает: в калькуляторе можно вводить цены вручную. Чтобы подтянуть цены локально: `npm run prices && npm run site-data` (нужен доступ к Steam/Skinport).

## Раскидки профи

**`.github/workflows/nades-all.yml`** разбирает весь архив про-демок OpenCS2 порциями по 480 карт в 16 параллельных задачах (следующая порция запускается сама; 4 из 20 мест для задач GitHub остаются сборке сайта). Из каждой демки (`tools/demos/extract_nades.py`, demoparser2) берутся броски с 3D-траекторией, кнопкой и названием места, позиции игроков с названиями мест (для коллаутов) и статистика с прицелами игроков. `tools/demos/build_lineups.py` собирает из этого раскидки, коллауты и профили игроков. Всё лежит в релизе `data-store` (`nades-raw`, `nades-proc`, `nades-site`), сборка сайта подкладывает `nades-site` в `public/data/`.

3D-геометрия карт для повторов — `public/maps3d/*.bin.gz`, собирается `tools/maps3d/build_meshes.py` из коллизионных мешей [awpy-data](https://github.com/pnxenopoulos/awpy-data) (карты © Valve). Русские названия коллаутов — `public/data/callouts/names.json` (с источниками по каждой карте).

## Мои матчи

Статистика матчей своего аккаунта в духе csst.at / Leetify: рейтинг Premier по матчам, результаты, K/D, ADR, HS, KAST, точность, первые дуэли, клатчи, мультикиллы, урон гранатами, карты, оружие и таблица всех 10 игроков. Компонент — `src/components/MyMatches.tsx`.

**`.github/workflows/my-matches.yml`** — каждые 30 минут (`scripts/my-matches.mjs`):
1. Steam Web API `GetNextMatchSharingCode` отдаёт коды новых матчей после последнего известного;
2. второй аккаунт Steam (`steam-user`) заходит в CS2 и спрашивает у координатора игры (`globaloffensive`) информацию о матче: счёт, K/D/A и ссылку на демку `replay*.valve.net`;
3. демка разбирается `tools/matches/match_stats.py` (demoparser2). Valve хранит демки несколько недель — для более старых матчей остаются данные координатора (`demo: false`);
4. `matches/<steamid>.json` сохраняется в релиз `data-store` (архив `my-matches`) и единственным коммитом в служебную ветку `stats-data`, откуда его читает сайт. Формат файла описан в начале `scripts/my-matches.mjs`.

Нужны четыре секрета (**Settings → Secrets and variables → Actions**); пока их нет, workflow просто пишет, каких не хватает, и завершается без ошибки:

| Секрет | Где взять |
|---|---|
| `STEAM_API_KEY` | https://steamcommunity.com/dev/apikey (домен — любой, например `localhost`) |
| `CS2_AUTH_CODE` | https://help.steampowered.com/ru/wizard/HelpWithGameIssue/?appid=730&issueid=128 → «Код аутентификации» (создать) |
| `CS2_LAST_SHARECODE` | там же — код последнего завершённого матча (`CSGO-xxxxx-…`), или в CS2: «Смотреть» → «Ваши матчи» → «Поделиться» |
| `STEAM_BOT_TOKEN` | токен **второго** аккаунта для Steam-клиента: `node scripts/steam-login.mjs --client` (как в разделе выше, но с `--client`). CS2 на нём покупать не нужно — бесплатная лицензия добавится сама |

SteamID64 владельца задан в самом workflow (`CS2_STEAMID`). Токен живёт ~200 дней: если вход перестанет работать, запуск упадёт с подсказкой — выпустите новый токен.

## Источники и лицензии

- База предметов: ByMykel/CSGO-API (MIT); официальные русские названия — из файлов игры через ByMykel/counter-strike-file-tracker (MIT). Изображения — CDN Steam, © Valve.
- Кодирование прицелов: [csgo-sharecode](https://github.com/akiver/csgo-sharecode) (MIT).
- Формат inspect-ссылок — по описанию [cs2-inspect-create](https://github.com/candyboyz/cs2-inspect-create) (MIT), своя реализация в `src/lib/inspect.ts`.
- Про-демки для раскидок: датасет [OpenCS2](https://huggingface.co/datasets/blanchon/opencs2_dataset_demo) (CC BY 4.0, зеркало демок HLTV) и [awpy-fixtures](https://github.com/pnxenopoulos/awpy-fixtures); разбор — [demoparser2](https://github.com/LaihoE/demoparser) (MIT).
- Свои матчи: [steam-user](https://github.com/DoctorMcKay/node-steam-user) и [globaloffensive](https://github.com/DoctorMcKay/node-globaloffensive) (MIT) — вход в Steam и координатор CS2; демки — с серверов Valve.
